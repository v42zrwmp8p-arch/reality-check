REALITY CHECK

Online ausprobieren:
https://finfluencer-reality-check.streamlit.app/
Besucher brauchen keine Python-Installation und keinen eigenen API-Key.

Bereiche: Import TikTok, Manual Entry, My Tracker, Case Database.
Die Case Database heisst im Inhalt Iconic market calls und enthaelt neun Faelle:
Roaring Kitty/GME, Cramer/Coinbase, Cathie Wood/ARK/Tesla, Pompliano/Bitcoin,
Cramer/Bear Stearns, Nikola Motors sowie Metahero, Kadena und MultiVAC.
Sieben besitzen gespeicherte Kursauswertungen. Nikola Motors zeigt den
Aktienannullierungsstatus; Bear Stearns ist ein Kontextfall ohne Aktienrendite.
My Tracker speichert die Eintraege im jeweiligen Browser.

Lokaler Start mit Python 3.12:
python -m pip install -r requirements.txt
python -m streamlit run app.py

Fuer lokalen TikTok-Import werden zusaetzlich FFmpeg, Tesseract und ein eigener
GROQ_API_KEY benoetigt. Einrichtung und Grenzen stehen in README.md.
Neue oeffentliche Quellen als weitere Zeilen in predictions.csv aufnehmen.
Quellenpruefung der oeffentlichen Beispiele: case_sources.json.
