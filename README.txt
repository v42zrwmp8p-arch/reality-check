REALITY CHECK

Aktuelle Projektbeschreibung und Einrichtung: README.md
App: https://finfluencer-reality-check.streamlit.app/

Bereiche: Import TikTok, Manual Entry, My Tracker, Case Database.
Die Case Database zeigt fuenf Faelle unter Iconic market calls.
Vier haben Kursvergleiche; Bear Stearns zeigt einen historischen Chart
der Crash-Woche ohne simulierte Aktienrendite. Die alten TikTok-Faelle
sind aus der aktiven Datenbank entfernt.
